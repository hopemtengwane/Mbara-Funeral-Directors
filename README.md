# Mbara Funeral Directors website

A responsive, static website concept for Mbara Funeral Directors. It uses plain HTML, CSS and JavaScript, so it can be hosted from GitHub Pages or another static host without a build step.

## Preview locally

Open `index.html` in a browser, or run a local static server from this directory, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

The first design uses online directory entries as provisional details:

- Cradock: 46 Adderley Street, Cradock, 5880 · 042 205 0255
- Komani: 24 Bushell Street, Komani, 5320 · 082 219 5145

Please confirm both addresses and numbers with the business before publishing. The site intentionally does not advertise funeral cover or insurance products, specific packages, opening hours, or services beyond general funeral arrangement guidance. Confirm any service wording with the company before making the website public.

The company logo in `assets/mbara-logo.png` was supplied for this site. The hero illustration is original CSS artwork.
